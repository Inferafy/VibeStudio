# 界面层：聊天与网格

模块定位：展示独立会话及其输入、消息和操作，在单会话与网格中复用。

所属分层：[界面层](../架构设计.md#1-总体与分层)。

对应代码：暂无正式实现；计划使用 `src/sessions/` 的聊天与网格部分及 `src/shared/`。

所属里程碑：[M2](../roadmap.md#m2)、[M3](../roadmap.md#m3)。

当前状态：未开始。

最近更新时间：2026-09-14。

## 职责与边界

- M2 展示历史、回复、工具记录、提问、审批、停止及错误恢复，落实固定 Agent 图标、权限和右侧模型、思考等级、上下文饼图。
- M3 复用同一面板实现网格放入、新建、替换、放大与移除；每个操作只作用于目标会话。
- 不管理 Agent 进程，不建设独立终端、编辑器或画布，也不承诺共享目录中的代码修改自动隔离。

## 结构与数据流

本地能力层的事件进入所属会话，单会话与网格读取同一份会话显示状态；输入和审批携带目标回到本地能力层，草稿和阅读位置按会话保留。

## 关键决策

沿用 [前端设计](../前端设计.md) 和 [并行归属规则](../架构设计.md#3-会话归属与并行)。显示模式与运行连接分开，详细消息组件、状态和网格接口在 M2、M3 分别确认。

## 会话展示调研

[会话内容与操作调研](../调研/会话内容与操作调研.md) 已对照 CodeG、Codex 和 Nimbalyst，形成以下候选边界：

- M2 统一展示用户消息、Agent 回复、思考、计划、工具、命令、文件摘要、审批、提问和错误；缺失能力按真实结果降级。
- 思考、长工具输出和完整差异默认收起；审批、提问、断线和失败保持可见。
- 首批候选操作包括复制、展开/收起、滚到底部、加载更早内容、回答审批与提问、重试、重连、发送和停止。
- 模型、模式、思考等级、权限和原生命令只在当前会话实际提供时显示。
- 消息转任务、回复处分叉、历史搜索、排队、完整终端和复杂会话管理继续后置，除非 M0 证明某项是基本接入所必需。

最终按钮集合在 M2 开工前确认；调研中的候选项不能当作已经实现的功能。

## 当前实现

已有单会话、2×2、3×3 静态展示和会话内容调研，尚无真实消息、菜单或并行操作。模型、权限、思考等级、原生命令和用量能力仍需 M0 验证。

## 验证方式

M2 验证真实对话、思考与工具折叠、命令输出、审批、提问、停止、旧历史和分类错误恢复；同时检查按钮只在对应能力和状态下可用。M3 验证混合 Agent 并行、面板操作不串线和小窗口输入区可见。消息与状态逻辑写单测，展示通过实际界面检查。

## 待扩展项

分阶段补齐聊天与网格详细设计；缺失能力的具体展示方式按 M0 结果确认。代码工具、画布和布局恢复不属于当前 MVP。

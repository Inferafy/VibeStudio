# 界面层：聊天与网格

模块定位：承载单会话内容，并把同一会话面板复用于多会话网格，管理布局、焦点和面板操作。

所属分层：[界面层](../架构设计.md#1-总体与分层)。

对应代码：暂无正式实现；计划使用 `src/sessions/grid/` 和 `src/shared/`。

所属里程碑：[M2](../roadmap.md#m2)、[M3](../roadmap.md#m3)。

当前状态：未开始。

最近更新时间：2026-09-14。

## 职责与边界

- M2 提供当前会话容器，把目标会话交给 [会话内容与操作](界面层-会话内容与操作.md) 模块展示。
- M3 复用同一面板实现网格放入、新建、替换、放大与移除；每个操作只作用于目标会话。
- 管理单会话与网格的布局、面板焦点、会话占用和尺寸适配，不实现消息、工具卡、输入区或审批内容。
- 不管理 Agent 进程，不建设独立终端、编辑器或画布，也不承诺共享目录中的代码修改自动隔离。

## 结构与数据流

工作台选择目标会话后，本模块把会话标识、面板尺寸和焦点状态交给会话内容模块。单会话与网格读取同一份会话状态；切换布局、放大或移除面板只改变显示关系。

## 关键决策

沿用 [前端设计](../前端设计.md) 和 [并行归属规则](../架构设计.md#3-会话归属与并行)。显示模式与运行连接分开，会话正文统一交给 [会话内容与操作](界面层-会话内容与操作.md)，本模块不复制其状态或操作逻辑。

## 会话模块边界

[会话内容与操作调研](../调研/会话内容与操作调研.md) 及内容类型、按钮、折叠、审批、提问和错误展示已归入独立模块。本模块只规定：一个会话在同一显示模式中只占一个面板，面板持有会话标识和视觉状态，不持有第二份消息或运行连接。

## 当前实现

已有单会话、2×2、3×3 静态展示，尚无 React 面板容器、布局状态或并行操作。Agent 基础能力已由 M0 验证；真实会话内容和网格归属仍在 M2、M3 实现。

## 验证方式

M2 验证单会话容器能挂载正确的会话内容并保留焦点、草稿和阅读位置。M3 验证混合 Agent 并行、同一会话不重复占位、面板替换/放大/移除不影响运行，以及小窗口输入区可见。布局状态逻辑写单测，纯展示通过实际界面检查。

## 待扩展项

M2、M3 分别补齐单会话容器和网格接口。布局保存、拖拽排列、代码工具、画布和工作区恢复不属于当前 MVP。

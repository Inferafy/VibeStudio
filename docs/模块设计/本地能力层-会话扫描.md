# 本地能力层：会话扫描

模块定位：只读整理 Claude Code、Codex 原生会话，并按真实项目目录组织。

所属分层：[本地能力层](../架构设计.md#1-总体与分层)。

对应代码：暂无正式实现；计划使用 `src-tauri/src/scanner/`。

所属里程碑：[M1](../roadmap.md#m1)。

当前状态：未开始。

最近更新时间：2026-09-14。

## 职责与边界

- 复用 CCSM 的来源解析、标题选择和项目分组，提供会话标识、目录、来源、标题和最近活动信息。
- 支持启动扫描与重新扫描，处理去重、缺失目录及损坏记录，单条错误不使全部结果失效。
- 不启动 Agent，不迁移、改写或删除原始记录，不根据扫描时间推测实时运行状态。

## 结构与数据流

读取必要扫描配置和两类原生记录，解析后整理项目与会话结果，交给界面列表；原生会话标识继续供运行模块关联上下文。

## 关键决策

遵守 [扫描路径](../架构设计.md#2-两条工作路径) 和 [技术选择](../技术设计.md#1-技术选择)。CCSM 复用范围、结果结构和异常返回在 M1 开工前确认。

## 当前实现

本项目尚无扫描代码；CCSM 是复用来源，界面中的会话列表仍为演示内容，不能视为已经完成移植。

## 验证方式

为来源解析、标题优先级、目录分组、去重和局部容错写单测；对比专用样本及真实会话结果，确认扫描不主动改写原始记录或触发 Agent。

## 待扩展项

M1 前补齐复用与结果设计；更多 Agent 来源、归档和历史画布关联后续按需求补充。

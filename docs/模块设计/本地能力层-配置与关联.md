# 本地能力层：配置与关联

模块定位：保存必要接入配置和客户端会话与原生会话的关联。

所属分层：[本地能力层](../架构设计.md#1-总体与分层)。

对应代码：[配置模块](../../src-tauri/src/settings/)、[应用状态](../../src-tauri/src/state.rs)。

所属里程碑：[M1](../roadmap.md#m1)、[M2](../roadmap.md#m2)。

当前状态：进行中。

最近更新时间：2026-09-15。

## 职责与边界

- M1 读取和保存扫描位置、刷新间隔及两类适配器的程序位置和参数覆盖。
- 没有用户覆盖时继续使用原工具与适配器的默认发现规则，配置文件只记录必要差异。
- M2 保存“来源 + 原生会话标识 + 工作目录”的有效关联，帮助运行模块恢复正确上下文。
- 不保存完整对话、密钥、令牌、Cookie 或原工具认证，也不改写 Claude Code、Codex 的配置文件。

## 配置结构

```text
src-tauri/src/settings/
  mod.rs        配置结构、默认值及后续读取保存入口
```

M1 配置固定为以下业务信息：

| 分组 | 字段                        | 规则                                               |
| ---- | --------------------------- | -------------------------------------------------- |
| 基础 | 格式版本                    | 首版为 `1`，遇到未知新版本停止写入并报告           |
| 扫描 | Claude Code 会话目录覆盖    | 可选绝对路径；空值使用默认位置                     |
| 扫描 | Codex 主目录覆盖            | 可选绝对路径；空值依次使用 `CODEX_HOME` 和默认位置 |
| 扫描 | 自动刷新秒数                | 默认 10 秒；界面和扫描防重入共同生效               |
| 接入 | Claude 适配器程序与参数覆盖 | 可选；不包含认证数据                               |
| 接入 | Codex 适配器程序与参数覆盖  | 可选；不包含认证数据                               |

M2 的会话关联在开工前继续确认字段和更新规则，本批不把它混入 M1 配置格式。

## 结构与数据流

配置文件保存在 Tauri 应用配置目录下的 `settings.json`。启动时读取一次并校验；界面修改后先写同目录临时文件，再原子替换正式文件。文件不存在时返回默认配置，不为默认值主动创建文件。

无效路径、无效刷新间隔和 JSON 解析失败都返回明确错误，保留原文件，不用默认值覆盖损坏内容。扫描和运行模块只接收已经校验的配置快照，不能在各自内部重复解释同一字段。

## 关键决策

- 配置格式带版本号，新增可选字段保持向后兼容；破坏性变化必须有迁移函数和样本测试。
- 程序路径和参数分开保存，Windows 启动时保持参数边界，不能把整条命令拼成一个 shell 字符串。
- 认证继续沿用原工具受支持的本机来源。设置页不得读取、回显或复制认证文件内容。
- 保存失败时内存中的已生效配置不切换，界面明确显示失败原因和重试操作。

## 当前实现

正式配置目录、首版结构和默认值已经建立，并由 Tauri 唯一应用状态持有；同一状态同时持有后续 ACP 运行实例，命令层只读取快照。磁盘读取、校验、原子保存及设置界面尚未实现，因此不会在本机创建配置文件。

## 验证方式

- 为缺失文件、合法配置、损坏 JSON、未知版本、相对路径、无效刷新间隔和原子替换失败编写单测。
- 验证保存与重开后字段一致，保存失败不覆盖原文件。
- 检查配置和诊断输出不包含原工具凭据内容。

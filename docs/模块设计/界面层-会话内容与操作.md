# 界面层：会话内容与操作

模块定位：把一个 Agent 会话的历史、实时过程、待处理请求和输入操作组织成统一会话页面。

所属分层：[界面层](../架构设计.md#1-总体与分层)。

对应代码：暂无正式实现；计划使用 `src/sessions/conversation/`、`src/sessions/composer/` 和 `src/shared/`。

所属里程碑：[M2](../roadmap.md#m2)。

当前状态：未开始。

最近更新时间：2026-09-14。

## 职责与边界

- 展示用户消息、Agent 回复、思考、计划、工具、命令、文件变化、审批、提问、错误和用量信息。
- 提供复制、展开/收起、加载更早内容、滚到底部、回答审批与提问、重试、重连、发送和停止等会话内操作。
- 根据当前会话的真实能力展示命令、模型、模式、思考等级、权限及输入附件入口。
- 保留会话草稿和阅读位置，历史加载与实时消息到达时不打断用户正在阅读的内容。
- 不负责项目与会话列表、网格布局、Agent 进程、ACP 连接、原始事件解析、独立终端、编辑器或画布。

会话内容与操作在单会话和网格面板中复用。网格只改变可用空间和信息密度，不创建第二份会话状态。

## 结构与数据流

```text
本地能力层的会话快照与增量事件
  -> 会话内容状态
       -> 消息时间线
       -> 过程卡片
       -> 待处理区域
       -> 输入区
  -> 用户操作携带会话、回合、工具或请求标识返回本地能力层
```

界面只消费已经归属到目标会话的业务事件。无法识别的内容进入通用事件卡并显示原类型，不在界面层猜测 Agent 含义。

## 会话内容

| 内容 | 默认展示 | 可用操作 |
| --- | --- | --- |
| 用户消息 | 文字、附件摘要、时间 | 复制 |
| Agent 回复 | Markdown、Agent、时间 | 复制；长内容正常阅读 |
| 思考或推理摘要 | 一行标题和状态，默认收起 | 展开/收起 |
| 计划或待办 | 当前步骤和整体进度 | 展开全部步骤 |
| 工具调用 | 名称、动作、状态 | 展开输入、结果和错误；复制结果 |
| 命令执行 | 命令、目录、状态和少量输出 | 展开完整输出；复制 |
| 文件变化 | 文件名、动作和增删摘要 | 查看协议已提供的差异；打开能力后置 |
| 审批请求 | 原因、目标和 Agent 提供的决策 | 选择一次后禁用全部按钮 |
| Agent 提问 | 问题、选项或输入 | 提交或取消 |
| 错误与通知 | 分类原因和主要恢复方式 | 重试、重连、登录或新会话，按实际能力显示 |
| 上下文与用量 | 输入区旁的简短状态 | 查看可靠数值和来源 |

详细来源及后续候选见 [会话内容与操作调研](../调研/会话内容与操作调研.md)。

## 输入与操作

- 输入 `/` 时读取当前会话命令快照，展示名称、说明和参数提示；命令消失后立即从未发送候选中移除。
- 选中的命令在界面中保持清楚标识，发送时还原成 Agent 需要的原始内容。
- 模型、模式、思考等级和权限控件只使用当前会话提供的配置，未知项不生成默认选项。
- 空闲时主操作为发送，运行时主操作为停止。运行中追加或排队只有在 M0/M2 实测确认后才显示。
- 审批和提问位于输入区上方或固定待处理入口，长回复不能把它们推走。
- 网格中的每次输入、审批、提问和停止都显式携带目标会话；视觉焦点不能改变操作归属。

## 关键决策

- 会话正文采用统一时间线，过程信息逐层展开；首屏优先呈现用户意图、任务进度、待处理事项和最终回复。
- 思考、长工具输出和完整差异默认收起，审批、提问、断线和失败保持可见。
- 按钮紧贴被操作的内容。回复旁放复制，过程卡内放展开，待处理卡内放决策，输入区只放当前会话操作。
- Agent 上报的选项决定功能可见性；本地展示元数据只能补充图标和文案，不能创造能力。
- 消息转任务、回复处分叉、全文搜索、复杂引用、完整终端和开发工具面板继续后置。

## 当前实现

已有 [单会话静态原型](../prototypes/vibestudio/single.html) 和 [会话展示调研](../调研/会话内容与操作调研.md)。尚无 React 会话时间线、真实事件订阅、操作处理或历史分页。

## 验证方式

- 为消息归并、增量工具状态、折叠状态、审批失效、提问提交、按钮可见性、草稿和阅读位置编写单测。
- 使用两类 Agent 的真实历史和实时事件验证内容类型、顺序、分页及未知事件降级。
- 验证复制、展开、审批、提问、重试、重连、发送和停止始终作用于正确会话。
- 人工检查单会话及网格中的长消息、长命令、空内容、加载、失败和窄面板；纯外观不编写单测。

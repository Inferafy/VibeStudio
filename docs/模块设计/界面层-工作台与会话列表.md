# 界面层：工作台与会话列表

模块定位：组织当前项目及其会话，提供开发工作台外壳。

所属分层：[界面层](../架构设计.md#1-总体与分层)。

对应代码：[工作台入口](../../src/app/App.tsx)、[会话栏](../../src/sessions/list/SessionSidebar.tsx)、[主题与基础控件](../../src/shared/)。

所属里程碑：[M1](../roadmap.md#m1)。

当前状态：进行中。

最近更新时间：2026-09-15。

## 职责与边界

- 展示项目栏、一级导航、会话列表、搜索、来源筛选及必要配置入口，复用统一主题和基础控件。
- 接收本地能力层的扫描结果，不直接读取原工具文件或启动 Agent。
- 保存界面选择、搜索条件和侧栏展开状态；这些状态不改变后台会话归属。
- 保留项目视图、画布和网格的位置。M1 不实现聊天、画布、网格及运行状态推断。

## 结构与数据流

```text
src/
  app/
    App.tsx                 工作台分区和当前界面状态
    WindowTitlebar.tsx      品牌区、拖动区和原生窗口操作
    app-shell.css           工作台布局及断点
  sessions/
    types.ts                与 Rust 扫描结果对齐的业务类型
    list/
      SessionSidebar.tsx    加载、空、错误及会话列表入口
  shared/
    components/ui/button.tsx 统一按钮和图标按钮
    lib/cn.ts               样式组合
    styles/                 主题 Token 与全局浏览器表面
```

扫描结果经 `src/sessions/api.ts` 进入目录状态，再由工作台选择当前项目和会话。搜索、来源筛选和排序使用前端纯函数处理，不修改 Rust 返回值。刷新失败时保留最近一次有效目录，同时在会话栏显示本次错误；首次扫描失败才显示完整错误状态。

界面状态固定为 `加载中`、`可用`、`空列表` 和 `读取失败`。原型里的会话、模型、运行数量和时间均为演示数据，正式代码不能用这些数据填充任何状态。

## 关键决策

- 视觉以 [前端设计](../前端设计.md#5-视觉规范) 和 [单会话原型](../prototypes/vibestudio/single.html) 为准，提取白色内容面、灰色工作台、细边界、6px 控件圆角和固定尺寸，不重新设计一套主题。
- 先建立主题 Token 和最小基础控件，再写业务组件。图标统一使用 Lucide；Agent 自有标识后续使用明确授权的品牌资源。
- 工作台保持三段结构：44px 项目栏、38px 一级导航、侧栏加主内容。1180px 以下收窄侧栏，640px 以下保留 56px 会话图标栏。
- 自绘窗口栏的最小化、最大化和关闭必须调用 Tauri 窗口能力；浏览器构建中安全忽略这些操作，不能抛出未处理错误。
- 纯样式不写单测。项目选择、搜索、来源筛选、排序和自动刷新防重入作为纯逻辑测试。

## 当前实现

正式 React 工作台骨架、主题 Token、基础按钮、自绘窗口操作、响应式会话栏和无演示数据的空状态已经建立。标题栏拖动与双击最大化交给 Tauri，按钮显式调用窗口能力。真实目录读取、搜索、筛选和项目切换尚未接入，因此 M1 仍为进行中。

## 验证方式

- 运行 TypeScript 严格检查、生产构建和 Rust/Tauri 构建。
- 接入扫描后，为项目选择、搜索、来源筛选、排序和刷新防重入运行单测。
- 在大于 1180px、860px、640px 和窄窗口四档检查布局；核对长标题、空列表、加载、读取失败、键盘焦点和窗口按钮。
- 禁止用原型截图或静态演示数据作为真实扫描完成依据。

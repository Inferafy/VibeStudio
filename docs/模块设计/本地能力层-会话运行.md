# 本地能力层：会话运行

模块定位：通过 ACP 连接正确的原生会话，管理消息、审批、停止和执行生命周期。

所属分层：[本地能力层](../架构设计.md#1-总体与分层)。

对应代码：暂无正式实现；计划使用 `src-tauri/src/acp/`。

所属里程碑：[M0](../roadmap.md#m0)、[M2](../roadmap.md#m2)、[M3](../roadmap.md#m3)。

当前状态：未开始。

最近更新时间：2026-09-14。

## 职责与边界

- M0 最小化验证原生标识、工作目录、连接、新建与旧上下文续接。
- M2 管理连接及事件归属，处理发送、提问、有效审批、停止和错误；界面切换不销毁执行。
- M3 验证并行与重复执行保护，退出只处理客户端自身启动的执行，不影响独立 CLI。
- 不自行执行编程工具业务，不复制完整历史到新数据库，不增加后台驻留平台。

## 结构与数据流

读取目标会话、目录与接入配置，通过现成协议库连接适配器；将回复和审批送回所属会话，把有效决定和停止操作送往同一执行目标。

## 关键决策

遵守 [聊天路径](../架构设计.md#2-两条工作路径) 和 [会话归属与并行](../架构设计.md#3-会话归属与并行)。进程复用、具体接口与内部状态在所属阶段开工前确认，本次不预设。

## 当前实现

尚无协议连接代码、可运行验证程序或已完成的兼容性结果。M0 的实测记录、M2 的聊天实现和 M3 的并行结果随阶段补齐。

## 验证方式

M0 验证旧上下文真正可辨识地续聊；M2 为消息归属、审批失效、停止与错误状态写单测，并真实检查生命周期；M3 检查并行不串线、重复执行和退出保护。

## 待扩展项

先确认 M0 验证设计并记录版本和能力结果，随后补齐 M2、M3 详细设计。后台任务驻留、远程执行和跨 Agent 上下文转换不属于当前 MVP。

# 本地能力层：会话运行

模块定位：通过 ACP 连接正确的原生会话，管理消息、审批、停止和执行生命周期。

所属分层：[本地能力层](../架构设计.md#1-总体与分层)。

对应代码：暂无正式实现；计划使用 `src-tauri/src/acp/`。

所属里程碑：[M0](../roadmap.md#m0)、[M2](../roadmap.md#m2)、[M3](../roadmap.md#m3)。

当前状态：进行中。

最近更新时间：2026-09-14。

## M0 目标与退出边界

M0 只建立“原生会话目标可以被正确找到并恢复”的最小证据，不实现完整聊天页面、消息数据库或后台任务系统。

M0 的运行模块必须证明：

- Agent、原生会话标识和工作目录可以组成稳定的会话目标。
- 新建会话返回的标识可以在进程结束后用于恢复同一上下文。
- 恢复失败会返回明确结果，不自动创建空白会话。
- 验证进程只影响本次由探针启动的子进程，不影响用户独立运行的 CLI。

## 职责与边界

- M0 最小化验证原生标识、工作目录、连接、新建与旧上下文续接。
- M2 管理连接及事件归属，处理发送、提问、有效审批、停止和错误；界面切换不销毁执行。
- M3 验证并行与重复执行保护，退出只处理客户端自身启动的执行，不影响独立 CLI。
- 不自行执行编程工具业务，不复制完整历史到新数据库，不增加后台驻留平台。

运行模块接收来自扫描或创建流程的目标，不根据当前项目、当前面板或最近活动时间猜测目标。生产实现中的协议细节在 M2 开工前继续收敛，M0 只固化恢复所需的最小契约。

## M0 最小对象

以下对象用于验证记录和后续接口讨论，字段含义先固定，具体 Rust 类型在实现时落地：

| 对象 | 必要信息 | 约束 |
| --- | --- | --- |
| 会话目标 | Agent、原生会话标识、规范化工作目录、适配器版本 | 恢复时四项必须来自同一条记录 |
| 运行句柄 | 子进程标识、适配器连接标识、会话目标、启动来源 | 只记录本客户端或探针创建的进程 |
| 运行事件 | 目标会话、事件类型、时间、可展示内容、原始事件定位 | 不复制完整历史，不丢失归属信息 |
| 运行结果 | 新建/恢复阶段、成功或失败、原因、证据位置 | 失败结果不能转成成功或新会话 |

会话的逻辑键是“Agent + 原生会话标识”。工作目录用于确认归属和启动位置，不替代原生会话标识。

## 结构与数据流

读取目标会话、目录与接入配置，通过现成协议库连接适配器；将回复和审批送回所属会话，把有效决定和停止操作送往同一执行目标。

M0 验证流程固定为：

1. 校验 Agent、适配器和工作目录配置，拒绝缺少原生会话标识的恢复请求。
2. 启动适配器并完成连接握手，记录进程所有权和实际启动信息。
3. 执行新建或恢复操作，保存适配器返回的原生会话标识和首批事件。
4. 将事件按逻辑会话键归档，检查工作目录和唯一记忆点是否一致。
5. 结束本次探针拥有的进程，生成可复核的运行结果。

M0 不要求界面订阅事件；探针可以直接输出结构化结果。M2 再把同一归属规则接到单会话界面。

## 关键决策

遵守 [聊天路径](../架构设计.md#2-两条工作路径) 和 [会话归属与并行](../架构设计.md#3-会话归属与并行)。

- M0 每个验证用例使用短生命周期进程，先验证连接和恢复事实，不评价长驻进程复用策略。
- 运行状态以实际收到的事件为准；扫描结果只描述会话存在，不能推断正在运行。
- 审批决定必须携带目标会话和请求标识。请求失效或已结束后，旧决定拒绝提交。
- 停止和退出只处理本次运行句柄标记为“由本客户端启动”的进程，不触碰用户单独启动的 CLI。
- 适配器崩溃、超时或恢复失败都保留原目标和错误原因，不能自动换成新会话。

具体进程复用、事件缓存和持久化接口在 M2 开工前确认；M0 不把验证探针直接当作生产运行管理器。

## M0 验证用例

| 用例 | 通过条件 | 失败处理 |
| --- | --- | --- |
| 新建会话 | 得到 Agent、原生会话标识和规范化工作目录 | 记录适配器输出和退出状态 |
| 恢复会话 | 使用原标识加载历史，未生成第二条会话 | 明确报告不兼容或参数错误 |
| 续聊记忆点 | 回复能证明读取了此前唯一记忆点 | 不能用标题或静态展示内容代替 |
| 归属检查 | 事件只进入目标会话，目录与 Agent 一致 | 丢弃无法归属的事件并保留错误 |
| 进程清理 | 只结束探针拥有的子进程，无遗留进程 | 记录清理结果，不扩大终止范围 |
| 异常恢复 | 超时、断开、错误均有明确结果且保留目标 | 不自动创建空白会话 |

M0 的能力结果和证据格式与 [Agent 接入模块](外部工具层-Agent接入.md#m0-能力矩阵) 对齐。

## 当前实现

## 验证方式

M0 使用专用项目和带唯一记忆点的会话验证旧上下文真正续聊，并检查目标归属和进程清理；M2 为消息归属、审批失效、停止与错误状态写单测，并真实检查生命周期；M3 检查并行不串线、重复执行和退出保护。

验证记录至少包含：目标会话、启动信息、关键事件顺序、恢复结果、清理结果和失败原因。原始输出不进入生产数据目录，也不记录认证秘密。
